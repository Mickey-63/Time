# Time

Application de présence et de suivi du temps (GIOT Immobilier SA / OptimalGo SA), version web.

- `site/index.html` : l'application, en un seul fichier.
- À chaque modification de `site/`, GitHub la dépose par FTP dans `/web/time/`, soit www.le-top.ch/time/.
- Les accès FTP sont dans les secrets du dépôt : `FTP_SERVER`, `FTP_USERNAME`, `FTP_PASSWORD`.

Données de démonstration fictives.
